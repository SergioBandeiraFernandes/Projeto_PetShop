# Projeto Petshop

A finalidade do projeto petshop é apresentar/montar um site funcional com as estruturas principais para a sua execução, conforme a solicitação do escopo do projeto da SCTEC.

Projeto foi executado pelo Sérgio Bandeira Fernandes de acordo com o que foi apresentado nas aulas, também através dos documentos extras apresentados pelo curso e por materiais externos.

## Funcionalidade
* Apresentação da empresa ficticia criada;
* Apresentação das seções com seu histórico, sobre a empresa, serviços e contato; e
* Processamento de dados do cliente através do formulário deixado na seção contato.

## Tecnologias
* Linguagem: javascript;
* Linguagem de marcação: HTML; e
* Linguagem de estilização: CSS.
